# 图集说明

本目录是 0.1.12 适配的界面图集，共 8 张场景图 + 1 张封面。

## 这些图是什么

- 布局、控件顺序、字号、间距与配色**按真实界面实测**（在 1936×1056 的窗口截图中逐像素取样：边距、行高、分隔线、`#2b7fff` 上下文条、`#fe9a00` 额度条、`#d4ceec` 额度卡）。
- 文字内容使用**演示数据**：`demo-workspace`、`gemini-4-neon`、`94%`、`¥86.42` 等，均为示例；不含真实项目、账号、会话或文件路径。
- 每张图同时提供两种格式：
  - `.svg`：矢量源文件，可无损放大、可再编辑。
  - `.jpg`：同一画面的高清位图（长边 2360–2560 px）。**JPG 不是矢量格式**，放大后会失真；需要放大请用 SVG。
- 图中橙色/黑色编号与虚线只用于讲解，**不是界面上真实存在的元素**；界面本身没有这些标注。

## 逐图说明

### 01-placement — 整体位置

整个 T3 Code 窗口。底栏在输入框内部的最下方一行，左侧是上下文与统计，右侧是额度入口。虚线框标出补丁新增的那一行；模型选择器、侧栏、右侧项目面板都是原生控件，未被替换。示例对话已明确标注为演示数据。

### 02-footer — 底栏放大

底栏一行内的四个区域：

1. **上下文入口** — `上下文` + 进度条 + `476k/1m` + `45%`。
2. **轮次与工具** — `10轮 · 工具114次 · 155词元/秒`。
3. **词元与缓存** — 竖线右侧的 `476.3K词元 · 命中95%`。
4. **额度入口** — 时钟图标 + `周额度` + `94%`。

### 03-context — 上下文面板

点击底栏「上下文」在输入框上方展开。标题、`已用45%`、`476k / 1m`、分段进度条（蓝＝已缓存，橙＝未缓存，灰＝剩余）、两类词元的绝对量与占比、`剩余空间`、`缓存命中`（最近一轮与会话），底部为本轮轮次与工具次数。达到压缩阈值时会多一行压缩预留。

### 04-quota — 额度面板

点击底栏「周额度」展开。第一行是**提供方实例 · 模型**与**账号归属**；卡片内是窗口名（周额度 / 5 小时）、剩余百分比、20 格额度条（每格 5%）、右侧刻度标记与下次重置倒计时；底部「全部额度」进入用量页的限制标签。

### 05-picker — 模型选择器

原生模型选择器：左侧提供商栏（收藏 / 各提供商）、搜索框、模型列表与 `Ctrl+1…5` 快捷键、右侧思考强度子菜单。补丁只做一件事：在每个模型行右侧显示该模型所属池的剩余额度（`94%`）。GPT 与 Claude 分属不同提供商行，不会被合并成一行。

### 06-limits — 用量页 · 限制

从「全部额度」进入。顶部是期限筛选（过去 24 小时 / 7 天 / 30 天 / 90 天）、`费用 / token / 限制` 三个标签与 `¥ CNY / $ USD` 货币切换。内容区按提供商分组，显示每个窗口的剩余额度、账号与重置时间；共享池以 `Claude & GPT (shared)` 原样标注；底部是原生 ChatGPT 用量入口。

### 07-cost — 用量页 · 费用

费用标签：人民币总额与估算口径、每小时费用曲线、处理的 token / 缓存输入 / 未缓存输入 / 输出 / 缓存节省、按类型统计的占比条、模型明细表（未定价模型保留原文）。货币切换只改变显示，不修改统计数据。

### 08-flow — 点击路径

把五个状态串起来：底栏 → 上下文面板 / 额度面板 → 用量页限制 → 用量页费用。所有浮层都在输入框上方展开，按 `Esc` 或点击空白处关闭；用量页是原生路由，可返回原会话。

## 重新生成

```powershell
node tools/showcase/build-showcase.mjs                    # 由脚本生成 9 个 SVG
ego-browser nodejs -e "await import('file:///.../tools/showcase/render-scenes.mjs')"  # 2 倍栅格化（任何浏览器亦可）
python tools/showcase/png-to-jpg.py <png-dir>             # 按长边 2560 输出高质量 JPG
```

SVG 由 `tools/showcase/showcase-lib.mjs` 中的绘图原语生成，任何文字都可直接修改后重新导出。
