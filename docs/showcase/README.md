# 图集说明

本目录是 0.1.12 适配的界面图集：**3 张主图** + **1 张总览** + **9 张细节图**。

## 这些图是什么

- 布局、控件顺序、字号、间距与配色**按真实界面实测**（1936×1056 窗口截图里逐像素取样：边距、行高、分隔线、`#2b7fff` 上下文条、`#fe9a00` 额度条、`#d4ceec` 额度卡）。
- **数值形态也按真实账号取样**：底栏是 `498k/1m 48% · 12轮 · 工具118次 · 192词元/秒 | 498.4K词元 · 命中95%`，右侧 `5小时 93%` 与 `周额度 40%` 两个入口；额度面板是这两张卡片；模型选择器里有 9 个模型、行内 `40%` 徽标；用量页限制标签是 `Gemini · 5-hour`、`Gemini · Weekly` 与两个 `Claude & GPT (shared)` 卡片。
- 具体数字是**演示值**（会随会话变化），但结构与真实界面一致；不含真实项目、账号、会话或路径。
- 每张图同时提供两种格式：`.svg`（矢量，可无损放大、可再编辑）与 `.jpg`（长边 2560 的位图）。**JPG 不是矢量格式**。
- 图中的编号、虚线只用于讲解，**不是界面上真实存在的元素**。

## 主图（README 顶部展示）

| 文件 | 内容 |

| `hero-overview` | 深色主图：整个 T3 窗口，底部一行状态栏；左侧是三条卖点。 |
| `hero-strip` | 深色主图：底栏一行 + 上下文面板 + 额度面板（5 小时 / 周额度）。 |

主图的深色背景、渐变与光晕是**展示用的包装**；里面的窗口、面板、图表都按真实界面绘制。

## 总览图

`overview-map`：五处入口在一张图里——底栏、上下文、模型选择器、额度、用量页，并附「阅读顺序」五步。

## 重新生成

```powershell
node tools/showcase/build-showcase.mjs                    # 生成 12 个 SVG
ego-browser nodejs -e "await import('file:///.../tools/showcase/render-scenes.mjs')"  # 2 倍栅格化
python tools/showcase/png-to-jpg.py <png-dir>             # 长边 2560 输出 JPG
```

SVG 由 `tools/showcase/showcase-lib.mjs` 的绘图原语生成；改文案或数值只需改生成器里的数据常量后重跑。
